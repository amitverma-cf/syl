# syl

A local-first agentic GUI app.

## Development

```bash
cargo build --workspace   # Rust workspace
pnpm --dir ui build       # frontend
pnpm tauri dev             # run the app (from src-tauri/, or via `pnpm --dir ui tauri dev`)
```
